عکس‌های واقعی (بدون حق‌نشر) خود را اینجا بگذارید؛ نصب‌کننده خودش آن‌ها را کوچک و بهینه می‌کند و وارد سایت می‌کند.

ساختار پیشنهادی (هر پوشه برای یک نوع اقامتگاه):
  villa/          عکس ویلاها
  cottage/        عکس کلبه‌ها          (اسم cabin هم قبول است)
  garden_villa/   باغ‌ویلا
  suite/          سوئیت
  eco/            بوم‌گردی
  apartment/      آپارتمان
  farm/           مزرعه و باغ
  tiny/           خانه چوبی             (اسم cabin هم قبول است)
  all/            عکس‌های عمومی (برای هر نوعی که پوشه‌ی اختصاصی ندارد)
  site/ یا همین‌جا:  hero.jpg  (عکس بزرگ صفحه‌ی اول)   و   login.jpg  (عکس صفحه‌ی ورود)

فقط jpg / png / webp. عکس‌ها بین اقامتگاه‌های هم‌نوع تقسیم می‌شوند.
اگر پوشه‌ی اختصاصی خالی بود، از پوشه‌ی all یا عکس‌های همین‌جا استفاده می‌شود.

بعداً هم می‌توانید عکس اضافه کنید:
  cd /var/www/mija && sudo -u www-data php artisan mija:photos --dir=/مسیر/photos
