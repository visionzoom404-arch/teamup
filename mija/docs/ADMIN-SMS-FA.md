# پیامک‌های هشدار مدیران

پیامک فقط برای اتفاق‌هایی می‌رود که نیاز به تأیید یا اقدام مدیر دارند (به‌علاوه‌ی اعلان داخل پنل).
گیرنده‌ها: همه‌ی مدیرانِ فعال + «شماره‌های اضافه» در تنظیمات ← پیامک. روشن/خاموش: تنظیمات ← پیامک ← «پیامک به مدیران هم برود».

| # | رویداد | چه زمانی؟ |
|---|--------|-----------|
| ۱ | میزبان جدید ثبت‌نام کرد | ثبت‌نام با نقش میزبان |
| ۲ | مدارک هویتی میزبان رسید | ارسال/تغییر کد ملی و مدارک — منتظر تأیید |
| ۳ | پرونده‌ی میزبان تکمیل شد | تکمیل هویت و حساب بانکی |
| ۴ | اقامتگاه جدید منتظر تأیید است | ارسال ملک تازه برای بررسی |
| ۵ | اقامتگاه ارسال‌شده منتظر تأیید است | ارسال مجدد ملک ردشده یا ویرایش‌شده |
| ۶ | درخواست برداشت جدید | درخواست برداشت میزبان |
| ۷ | پرداخت کارت‌به‌کارت جدید | ارسال رسید توسط مهمان — منتظر تأیید |
| ۸ | تبلیغ جدید منتظر تأیید است | ثبت تبلیغ توسط میزبان |
| ۹ | سفارش طراحی بنر | درخواست طراحی بنر از پشتیبانی |
| ۱۰ | نظر ردشده توسط میزبان | نظر مهمان را میزبان رد کرده؛ مدیر باید تصمیم بگیرد |

ثبت‌نام مهمان نیاز به تأیید ندارد و فقط در «اعلان‌ها» دیده می‌شود.
